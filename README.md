# Nintendo TV

A synchronized live channel built from full Nintendo-related cartoons and TV episodes sourced from authorized/verified uploads.

## Channel rules
- Nintendo-related programming only.
- Full cartoons, TV episodes, or full movies only.
- No merchandise, shirt/product videos, trailers presented as programs, or unrelated filler.
- Schedule changes at 12:00 AM in the viewer's local time.
- Unused time in each program block is labeled Intermission and reserved for future advertising.
- Player joins the currently airing program at the correct live offset.
